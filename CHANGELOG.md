# Changelog

## 1.2.0 — 2026-09-06

- Added an in-app language selector with automatic Windows-language detection.
- Added complete English and Russian interface translations, including tray menus,
  status text, notifications, widget actions and error dialogs.
- Added English and Russian README files and localized installer options.
- Updated repository and download links for the `KhromotozzDevOut` account.

## 1.1.0 — 2026-09-06

- Generalized the product UI from Chimera to supported ARDOR wireless mice.
- Confirmed the shared CompX protocol and USB IDs in official driver packages for
  Chimera, Essence, Phantom, Prime Wireless, Ulta and Immortality PRO Wireless.
- Added Nordic/CompX transport profiles for Harpy, Impact PRO and Phantom PRO V2.
- The “open ARDOR software” action now searches installed ARDOR model folders.

## 1.0.0 — 2026-09-06

- Direct battery reading from ARDOR GAMING Chimera over USB HID.
- Support for wired `PID_FA7B` and 2.4 GHz receiver `PID_FA7C` modes.
- Sharp, pixel-rendered percentage in the Windows notification area.
- Low-battery notifications.
- Optional transparent always-on-top percentage widget.
- Configurable widget position, size, and opacity.
- Explicit move/lock mode; the locked widget is click-through.
- Per-user autostart option, portable build, and installer packaging.
