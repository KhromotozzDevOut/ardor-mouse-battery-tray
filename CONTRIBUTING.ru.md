# Участие в разработке

[English version](CONTRIBUTING.md)

Мы приветствуем сообщения об ошибках и проверенные данные о новых устройствах.

Для добавления новой мыши ARDOR укажите:

- точную модель и артикул;
- аппаратные ID мыши при проводном подключении и USB-ресивера из Диспетчера устройств Windows;
- ссылку на официальный пакет ПО ARDOR/DNS;
- вывод команды `--probe`, если доступна консольная сборка;
- проверялся ли процент заряда по официальной программе.

Не определяйте протокол только по модели сенсора. Команды чтения батареи должны применяться
только к подтверждённым парам VID/PID и проверенным ответам устройства.

Сборка выполняется скриптом `build.ps1` в Windows 10/11. Приложение должно оставаться
самодостаточным, без телеметрии и сетевого доступа во время работы.
