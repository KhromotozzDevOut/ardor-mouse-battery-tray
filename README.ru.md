# ARDOR Mouse Battery Tray

[English version](README.md) · [Скачать последнюю версию](https://github.com/KhromotozzDevOut/ardor-mouse-battery-tray/releases/latest)

Небольшой индикатор заряда для совместимых беспроводных мышей ARDOR GAMING. Он показывает
заряд крупными цветными цифрами в области уведомлений Windows и в необязательном виджете
поверх окон.

Это неофициальный проект сообщества, не связанный с ARDOR GAMING.

Утилита отправляет мыши только команду чтения батареи, которую использует фирменная
программа. Настройки, DPI, назначение кнопок и память мыши она не изменяет. Программа ARDOR
может работать одновременно с индикатором, но для его работы не требуется.

## Поддерживаемые мыши

| Модель | USB VID/PID | Статус |
| --- | --- | --- |
| Chimera | `25A7:FA7B/FA7C` | проверено на реальной мыши |
| Essence | `25A7:FA7B/FA7C` | подтверждено официальным пакетом ПО |
| Phantom / Phantom Wireless | `25A7:FA7B/FA7C` | подтверждено официальным пакетом ПО |
| Prime Wireless | `25A7:FA7B/FA7C` | подтверждено официальным пакетом ПО |
| Ulta | `25A7:FA7B/FA7C` | подтверждено официальным пакетом ПО |
| Immortality PRO Wireless | `25A7:FA7B/FA7C` | подтверждено официальным пакетом ПО |
| Harpy | `3554:F511/F53C` | реализован Nordic/CompX-профиль; требуется проверка владельцем |
| Impact PRO | `3554:F59A/F53C` | реализован Nordic/CompX-профиль; требуется проверка владельцем |
| Phantom PRO V2 | `3554:F52E/F52D` | реализован Nordic/CompX-профиль; требуется проверка владельцем |

Несколько моделей используют один аппаратный ID, поэтому Windows не позволяет надёжно
отличить их друг от друга. В интерфейсе они отображаются как `ARDOR CompX` или
`ARDOR Nordic/CompX`. Неподтверждённая мышь не опрашивается: совпадение бренда или сенсора
само по себе не означает совместимый протокол.

Если вашей модели нет в таблице, [создайте issue](https://github.com/KhromotozzDevOut/ardor-mouse-battery-tray/issues/new)
и приложите точное название мыши, аппаратные ID проводного подключения и ресивера, а также
ссылку на официальное ПО. Полный список указан в [CONTRIBUTING.ru.md](CONTRIBUTING.ru.md).

## Возможности

- чёткий цветной процент заряда в трее Windows;
- прозрачный виджет поверх обычных и полноэкранных окон без рамки;
- четыре угловых и свободное закрепляемое положение;
- четыре размера и четыре уровня прозрачности;
- предупреждения при 20%, 10% и 5%;
- необязательный автозапуск для текущего пользователя Windows;
- русский и английский интерфейс с автоматическим выбором языка Windows;
- без телеметрии, рекламы, сетевого доступа, Python и сторонних сред выполнения.

## Язык

По умолчанию приложение использует язык Windows: русский для русскоязычной системы и
английский для остальных языков. Чтобы выбрать язык вручную, щёлкните значок в трее правой
кнопкой и откройте **Язык → Русский**, **English / Английский** или **Как в системе**.
Интерфейс переключается сразу, а настройка сохраняется после перезапуска.

## Использование

1. Запустите `ArdorBatteryTray.exe`.
2. Наведите курсор на цветное число в области уведомлений, чтобы увидеть мышь и режим связи.
3. Дважды щёлкните значок для уведомления с текущим состоянием.
4. В контекстном меню можно обновить показание, настроить виджет, включить автозапуск,
   открыть программу ARDOR, изменить язык или закрыть утилиту.

### Виджет поверх окон

Включите **«Показывать виджет поверх окон»**. В меню можно выбрать угол экрана, размер и
прозрачность. Для свободного положения нажмите **«Переместить виджет…»**, перетащите число
и выберите **«Закрепить виджет здесь»**. После закрепления виджет становится некликабельным
и не мешает управлению в играх, пока режим перемещения не будет снова включён.

## Установка и распространение

- `ArdorBatteryTray-Setup-v1.2.0.exe` — обычный установщик без прав администратора;
- `ArdorBatteryTray-v1.2.0-portable.zip` — переносная версия без установки;
- `SHA256SUMS.txt` — контрольные суммы опубликованных файлов.

Поддерживается Windows 10/11. Фирменная программа ARDOR не обязана быть установленной или
запущенной. Неподписанный установщик может вызвать предупреждение Microsoft SmartScreen.
Для публичного релиза без такого предупреждения потребуется сертификат подписи кода.

Заряд опрашивается раз в 30 секунд. Если мышь уснула, последнее достоверное показание
сохраняется пять минут.

## Сборка

Запустите `build.ps1` в Windows. Используется встроенный компилятор .NET Framework;
сторонние пакеты и доступ к интернету не требуются. `release.ps1` создаёт portable ZIP,
контрольные суммы и, при наличии Inno Setup 6, пользовательский установщик.

Для диагностики протокола запустите `ArdorBatteryTray.exe --probe`. Консольная сборка
печатает одно текущее показание и завершается.

Протокол CompX проверен по установленному драйверу ARDOR и на подключённой Chimera.
Идентификаторы остальных моделей получены из официальных пакетов ПО ARDOR/DNS. Для
дополнительной сверки использовалась открытая реализация Mouse Battery Tray
(MIT, copyright 2026 incconu_two).
